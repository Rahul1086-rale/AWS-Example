### Object Storage
- manage data as a object

#### S3 Objects
- consist of Key, value, versionID, metadata

#### S3 Bucket
- holds objects and also have folders which in turn hold objects
- S3 is universal namespace so bucket name must be unique
- 0 byte to 5 TB of single object
- cannot use _ and capital letters in bucket name
- object ownership - ACLs
- Encryption type
  - server side encryption with amazon s3 managed keys (SSE-S3)
  - server sider encryption with aws key management service key (DSSE-KMS)
  - dual layer service sider encryption with (DSSE-KMS)
- bucket versioning
- object locking
- bucket must be empty before they can be deleted

##### Storage Class
- don't need to copy explicitly

- S3Api
- S3 commands (cloud shell/CLI)

#### Example Commands

- remove files
  - aws s3 rm s3uri --recusive 
- remove bucket
  - aws s3 rb s3uri 
- create bucket 
  - aws s3 mb s3uri

## s3api
  - query is case sensitive

  - copy-object
    - Creates a copy of an object that is already stored in Amazon S3.
  - put-object
    - Adds an object to a bucket.
    - --content-type 
    - --body <file.name>

  - Examples
    - aws s3api list-buckets --query "Buckets[].Name" --output table
    - aws s3api list-objects --bucket bucket-rt-ltp-50 --query Contents[].Key
    - aws s3api create-bucket --bucket bucket-rt-ltp-50 --region us-east-1
    - aws s3api get-object --bucket bucket-rt-ltp-50 --key S3.md S3.md
